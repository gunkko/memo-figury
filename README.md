# Мемо фигуры

Игра на память, разработанная на Three.js для лабораторной работы №3.

Игрок открывает карточки и ищет одинаковые фигуры.
Совпавшие карточки остаются открытыми, разные — закрываются.
Цель — найти все пары до окончания времени.

## Возможности

- Объёмные карточки с плавным переворотом.
- Случайное расположение пар.
- Счётчики найденных пар и попыток.
- Таймер, победа и завершение по времени.
- Пауза с остановкой времени и скрытием поля.
- Автоматическая пауза при переключении вкладки.
- Перезапуск раунда.
- Звуки карточек и кнопок.

## Сложность

| Уровень | Карточки | Пары | Время |
| --- | --- | --- | --- |
| Лёгкий | 12 | 6 | 2 минуты |
| Обычный | 16 | 8 | 3 минуты |
| Сложный | 20 | 10 | 4 минуты |

Сложность выбирается перед началом раунда.

## Управление

- «Начать» — запустить раунд.
- Нажатие на карточку — открыть её.
- «Пауза» или Esc — приостановить игру.
- «Продолжить» или Esc — продолжить игру.
- «Заново» — сбросить раунд и перемешать карточки.

## Запуск в Windows

Необходимы Node.js и npm.

Откройте терминал в папке проекта и выполните:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте адрес, который появится в терминале.

## Сборка

```powershell
npm.cmd run build
```

Готовые файлы создаются в папке `dist`.

Для проверки сборки:

```powershell
npm.cmd run preview
```

Откройте адрес из терминала.

## Структура проекта

- `src/main.js` — сцена Three.js, карточки и игровая логика.
- `src/ui.js` — интерфейс, счётчики и выбор сложности.
- `src/config.js` — настройки уровней.
- `src/pause.js` — пауза и обработка переключения вкладок.
- `src/audio.js` — воспроизведение звуков.
- `public/sounds/` — звуковые файлы и сведения об их происхождении.

## Принципы разработки

- SoC: интерфейс, настройки, пауза и звук разделены по модулям.
- DRY: карточки создаются циклом, воспроизведение звуков использует общую функцию.
- KISS: используются простые состояния игры и стандартные средства браузера.
